Small research tools I built for my own work and made public in case they are useful to others.

### [X-ray Archive Finder](/tools/xray-archive-finder/)

Type a source name (any SIMBAD identifier) or coordinates and see how many observations exist in the NASA HEASARC archive for each X-ray mission — Chandra, XMM-Newton, Swift, NuSTAR, NICER, XRISM, IXPE, INTEGRAL, Suzaku, RXTE, ROSAT, ASCA, BeppoSAX, EXOSAT, Ginga and more — with dates, exposure times and observation IDs. It shows the source side by side in optical, X-ray and radio images, draws a smoothed X-ray image with radio contours (downloadable as PNG or FITS), lists and plots catalogue fluxes from the main X-ray (CSC, 5XMM, 2SXPS, eRASS1, 2RXS, NuSTAR, Swift-BAT, INTEGRAL) and radio (VLASS, NVSS, FIRST, RACS, SUMSS, WENSS, GLEAM, TGSS, LoTSS) source catalogues with a radio spectral-index fit, and plots the SDSS, BOSS or DESI optical spectrum interactively when one exists. A batch mode takes a file with up to 500 names or coordinates and returns the same counts and fluxes for all of them as a CSV table.
